# История изменений

Все изменения по порядку, от исходной версии до текущей. Подробности — в README (разделы 16–21).

1. **Исправления и превью.** Превью у каждого поста по цепочке (фото → обложка страницы → фото по ссылке →
   ссылочное превью); старые zip-посты берутся с сайта; взаимная блокировка при отправке больших файлов;
   имена ZIP в meta-режиме; статус «частично»; регистр поиска и NULL в сортировке в Postgres; переподключение к
   Postgres; нижняя клавиатура вместо россыпи кнопок; архивы по ссылкам (Mediafire/Pixeldrain/ouo.io без обхода
   капчи) с нарезкой на ZIP-части < 50 МБ; «Опубликовать всё» из поиска с паузой между постами.
2. **Импорт всего сайта.** От старейшей страницы к новейшей; кнопка «Остановить» с запоминанием позиции в БД;
   история публикаций с метками; история поиска; листание с кнопками «в начало»/«в конец»; антибан (случайные и
   длинные паузы, ожидание при блокировке); видео и «только архивы» не публикуются, а попадают в историю;
   отдельный модуль Mediafire.
3. **Дослать/перепроверить/ZIP/флуд.** Докачка комментариев с места обрыва, «Переопубликовать»; перепроверка
   пропущенных; лимит и отключение ZIP (`zip_max_mb`, `import_zip`); автозамедление при флуд-лимите Telegram.
4. **MTProto.** Файлы до 2 ГБ через Telethon (по токену бота): напрямую в чат админа, в канал/группу — через
   загрузку в личный чат и copyMessage; `/mtproto`, `/mttest`.
5. **Видео, подписи, поиск, дубликаты, подписки, CSV, структура.** Видео из плееров находится и учитывается
   (`video_embeds`), скачивание через yt-dlp; архивы называются «Ник – персонаж (игра)»; быстрый поиск
   (`search_text`, один запрос, кэш, индексы); поиск дубликатов; подписки с дайджестом; экспорт в CSV;
   монолит `mitaku_bot.py` разделён на пакет `botapp/`.
