# Тесты

Тесты работают на заглушках (`tests/stubs`: aiogram, telethon, yt_dlp, aiohttp), поэтому не требуют сети,
токена бота и установленных библиотек Telegram. Они проверяют логику: кнопки и экраны, превью, очередь
публикации, импорт сайта (остановка/продолжение/блокировка), историю, дубликаты, подписки, CSV, MTProto,
видео, нарезку архивов. Нужны только `requests`, `beautifulsoup4`, `Pillow`.

Запуск из корня проекта:

    for t in test_bot test_import test_mt test_video test_features; do python tests/$t.py; done

Каждый файл завершается кодом 0, если все проверки (строки `OK`) прошли. Заглушки не заменяют реальный
Telegram: это проверка логики, а не интеграции.
